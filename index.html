Tujuan Pembelajaran IPAS Kelas 4

Setiap astronot cilik akan menguasai kemampuan luar biasa berikut ini!

1. Mengenal Pusat Tata Surya

Peserta didik mampu mengidentifikasi Matahari sebagai pusat dari Sistem Tata Surya yang memancarkan cahaya dan panasnya sendiri.

2. Mengidentifikasi 8 Planet Utama

Peserta didik dapat menyebutkan urutan 8 planet dari yang terdekat hingga terjauh dari Matahari secara tepat.

3. Menganalisis Karakteristik Planet

Peserta didik mampu membedakan ciri khas unik setiap planet (seperti planet terbesar, planet tercantik berdinding cincin, dan planet merah).

4. Menjelaskan Benda Angkasa Lainnya

Peserta didik dapat mengenal peran Bulan/Satelit, Asteroid, Komet, dan Meteoroid yang ada di lingkungan tata surya kita.

Informasi Media Pembelajaran

Website Petualangan Antariksa ini dirancang secara khusus sebagai media pembelajaran interaktif berbasis web untuk mendukung mata pelajaran Ilmu Pengetahuan Alam dan Sosial (IPAS) Kelas 4 SD pada topik Sistem Tata Surya.

Media ini memanfaatkan prinsip visualiasi berwarna cerah, animasi interaktif, efek suara (audio synth), kuis evaluasi otomatis, serta permainan bongkar pasang (drag and drop) agar siswa SD Fase B dapat memahami konsep astronomi dasar secara menyenangkan, aktif, dan mandiri.

Teknologi Digunakan:

HTML5, CSS Tailwind, FontAwesome, JavaScript Single Page Application, Web Audio Synthesizer.

Karakteristik Siswa:

Ramah anak (Child-friendly), font readable ukuran besar, touch-friendly untuk tablet & smartphone.
